# NTI MEAN Stack Bootcamp 

Welcome to my repository for the **MEAN Stack Bootcamp** at the **National Technology Institute (NTI) of Egypt**. This repo contains all my daily labs, weekly assignments, and practical projects.

## Technologies Covered
* **M**ongoDB (NoSQL Database)
* **E**xpress.js (Backend Framework)
* **A**ngular (Frontend Framework)
* **N**ode.js (Runtime Environment)

## Repository Structure
* `/NodeJS-Express/` - Backend server basics, APIs, and routing.
* `/MongoDB/` - Database schemas, aggregation, and integration.
* `/Angular/` - Single Page Application components, services, and routing.
* `/Projects/` - End-to-end full-stack applications.
